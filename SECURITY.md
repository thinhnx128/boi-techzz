# Security Policy & Coordinated Vulnerability Disclosure

## Reporting a Vulnerability

Please report security vulnerabilities privately via the [GitHub Security Advisories](https://github.com/thinhnx128/boi-techzz/security/advisories/new) tab.

## Scope

- CWE-22: Improper Limitation of a Pathname to a Restricted Directory (Path Traversal / Zip-Slip)
- CWE-78: Improper Neutralization of Special Elements used in an OS Command (OS Command Injection)
- CWE-352 / CWE-306: Cross-Origin Localhost Callback & Missing Authentication State
- CWE-400: Uncontrolled Resource Consumption (Unbounded Stream / Memory Exhaustion)
- CWE-502: Deserialization of Untrusted Data
- CWE-918: Server-Side Request Forgery (SSRF & DNS Rebinding)
